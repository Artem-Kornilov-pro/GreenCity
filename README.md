## 🎯 Актуальность

Развитие и поддержка зелёного каркаса мегаполиса требует учёта множества ограничений: подземных сетей, плотности застройки, инфраструктуры и климатических факторов. Сегодня значительная часть решений по озеленению принимается **вручную**, без системной интеграции с пространственными и инженерными данными, что снижает эффективность и может вести к конфликту с подземными коммуникациями.

Например, при проектировании городского озеленения необходимо строго соблюдать нормативные отступы от подземных инженерных сетей (кабели, водопроводы, газопроводы):

- СП 42.13330.2016;
- Постановление Правительства Москвы № 743-ПП (например, не менее 2 метров от трубопроводов);
- МГСН, Постановление Правительства Москвы № 623-ПП.

В условиях цифровой трансформации и развития устойчивых городов актуально создание ИИ-сервиса, который сможет предлагать решения на основе объективных данных и типовых моделей. Автоматизация этого процесса ускорит создание проектов благоустройства и снизит срок проведения строительно-инвестиционного цикла.

&nbsp;
## 🧩 Описание задачи

Разработайте **ИИ-агента (алгоритм генеративного дизайна)**, который будет:

1. Использовать данные геоинформационных систем, в том числе данные «Геотреста» (геоподосновы), публичных кадастров, инженерных коммуникаций и функционального зонирования;
2. На основе встроенной аналитической модели рекомендовать **оптимальные локации** для размещения типовых зелёных посадок (деревья, кустарники, травянистые покрытия, скверы и др.);
3. Автоматически генерировать **оптимальный план посадки** деревьев и кустарников, соблюдая нормативные отступы от сетей и инфраструктуры;
4. Обеспечивать возможность внесения корректировок в **текстовом и графическом формате**.

Итоговый план должен экспортироваться обратно в формат **DXF**.

&nbsp;
## 📦 Ресурсы

- Примеры чертежей (DXF) с размеченными коммуникациями;
- Наборы параметров для тестовых участков озеленения;
- Обезличенные подосновы от АО «Мосгеотрест» (возможны примеры в формате DWG, SHP или GeoJSON);
- Открытые геоданные Москвы: улицы, здания, границы участков, транспортная инфраструктура (портал data.mos.ru);
- Каталоги типовых посадок с нормами по отступам и условиям посадки;
- Справочные данные по инженерным сетям, зонам охраны, охранным зонам ЛЭП и др.;
- Пространственная основа (open-source картографические платформы, например, Leaflet или Mapbox).

&nbsp;
## 🚀 Описание итогового продукта

Программный продукт (ИИ-агент / веб-сервис генеративного дизайна с модулем импорта/экспорта DXF):

- Прототип веб-сервиса или модуля, который по заданной территории предлагает список точек и зон, где возможна посадка зелёных насаждений;
- Визуализация типовых посадок с учётом ограничений;
- Алгоритм принятия решения (описанный и реализованный, возможно с использованием ML/ИИ);
- Сценарий выгрузки/генерации документации для внедрения предложенного решения.

# 00_empty_plot — пустой участок

Синтетический прямоугольный участок **100 × 70 м**, без зданий, охранных зон
и существующих посадок — только граница территории (слой `TERRITORY_BOUNDARY`,
как в остальных `locations/`, единицы — метры, `$INSUNITS=6`).

Нужен для двух сценариев, где реальная локация только мешает:

1. **Ручная расстановка** — загрузить `00_empty_plot.dxf` через загрузку DXF в
   редакторе, получить чистую сцену и расставлять деревья/кустарники из
   каталога вручную, без построек и чужих посадок под ногами.
2. **Автогенератор** — тот же файл можно скормить `/api/generate-greenery`
   (или прогнать `parser/parse_dxf.py` + `backend/generation/greenery_generator.py`
   напрямую) — свободная зона на всю площадь участка, ничего не режет
   раскладку.

Проверено на живом стеке (`docker compose`): `POST /api/parse` отдаёт
корректный `Scene` (1 полигон границы, 0 зданий, 0 зон), `POST
/api/generate-greenery` на нём отрабатывает без ошибок и расставляет объекты
(деревья/кустарники/газон) по всей площади.

Файл создан скриптом на `ezdxf` (не экспортирован из CAD) — если нужен другой
размер/форма участка, проще сгенерировать заново, чем редактировать руками.
